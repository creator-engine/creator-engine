  package `schemas/`). One loader fix; the ~50 `SCHEMA=` constants are untouched.

  (`CODEX_TRANSCRIPT_SETTLE_S`, capped at the deadline) before its FIRST poll, killing the cold/idle-codex
  transcript-locator race (live-reproduced 2026-06-13). Reuses the existing poll/timeout machinery.
- **ce-ops#58** — `spawn_review_venue` (`v3_seat_bridge.py`) gains a fail-closed step-2.5 guard: after
  `ce lane launch`, before `seed_brief`, it probes `gh api user --jq .login` through the `runner` seam,
  sourcing the SAME seat-env the review will (so it sees the review's identity), and refuses
  (`mark_spawn_failed` + `SpawnRefused`, pane conserved) when the venue login ≠ the envelope `actor` — the
  #218 wrong-identity leak. The bridge keeps a LOCAL copy of the seat-env wrap script (it imports no v1
  module; `lane_runtime` is v1-classified), kept byte-identical by a drift-guard test.
