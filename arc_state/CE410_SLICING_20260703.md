## Operator TL;DR (from design)
Conveyor daemon + integrator belt stay inert because arming today would allow: (a) payload
self-marking as daemon-owned via a default-True bool instead of a real allocation; (b) validation
subprocesses inheriting the full daemon env (GH_TOKEN, wall secrets, SSH/cloud keys); (c) one
credentialed git/gh env shared across transport and local git phases. Chosen trust model:
unforgeable daemon-issued objects — DaemonPathAllocation/Receipt for paths; three typed contexts
(TransportCredentialContext / LocalGitContext / ValidationSandboxContext); credentialless
ValidationSandboxRunner ideally on the worker-container-policy substrate (role verification, empty
secret/egress allowlists). No gate weakened. Armed mode stays REFUSED until all four phases land
with independent review; re-arming needs an evidence bundle + Operator ratification.
