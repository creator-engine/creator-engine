Install

There is no install wizard.

You hand your coding agent a signed playbook. It verifies the signature, then sets up Creator Engine itself — governed from the first step.

Install Creator Engine
from your terminal $ curl -fsSL https://creator-engine.dev/install.sh | bash
hand the signed playbook to your coding agent
claude claude "$(curl -fsSL https://creator-engine.dev/llms-install.md)"
codex codex "$(curl -fsSL https://creator-engine.dev/llms-install.md)"

The playbook is signed. A detached OpenSSH signature over its canonical bytes; your agent verifies it against the pinned trust root (ce-root-v1) with stock ssh-keygen — before executing a single step. Governance starts at hello.
