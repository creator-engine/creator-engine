# Creator Engine v3.5 — Program Plan (to the NVIDIA pitch, and beyond)

The single, dependency-ordered plan for *where we are* and *how we get to the
goal*. It turns the open `ce-ops` / `creator-engine` backlog from a flat ticket
list into **workstreams → waves → the pitch**. Update it when a workstream's
state materially changes; keep it derivable from `git log` + the issue tracker.

> **v3 is done and released** (v3.1 "pilot-ready" reached — see the historical
> gate-map in [`v3-roadmap.md`](v3-roadmap.md)). Forward planning lives **here**.

## 1. Goal & Definition of Done

**North star:** make CE the leading governed-SDLC automation layer for solo /
small teams; present-compatible, future-proof; OSS (partnership + NVentures +
Inception, **not** acquisition).

**The pitch (≈ Sept 2026, RTX / OpenShell launch — moved from 01-Jul at NVIDIA's
request for live users + data first). DoD:**
1. **Fully-containerized CE** — *every* agent contained, including the controller
   (the "every agent contained" headline; OpenShell-targeted, gVisor today).
2. **~100 live waitlist users** in production — ~70% agent-native builders with no
   pro-dev experience (the "consumers → builders" thesis made real), ~30%
   experienced devs converting to contributors.
3. **Live usage data** from those users (the evidence NVIDIA asked for).

**Post-pitch / v4 horizon:** stay **Python through v4.0**; runtime/language change
is trigger-gated (T1–T7); if porting, **validator-core-first → Go**. Experiments
deferred until after the pitch.

## 8. OpenClaw prior-art inputs (2026-06-19 research)

Distilled from a read-only survey of Peter Steinberger's **OpenClaw** ecosystem
(23 repos; full report archived at
`.ce/state/research/OPENCLAW_CE_RESEARCH_20260619.md`). OpenClaw is the closest
existing autonomous "dark factory"; its strongest pattern is **autonomous agents
behind durable job records, explicit state machines, deterministic apply gates,
and operator-visible evidence.** CE is directionally aligned — the survey
sharpened five plan changes (now folded into the workstreams above):

1. **WS-2 — build the throughput stack now, *composable* not monolithic.** Minimal
   set to copy: GitHub operational mirror/cache (`gitcrawl`/`octopool`) → durable
   work-item schema with snapshot + head-SHA replay guards (`clownfish`/
   `clawsweeper`) → **proposal/apply split** (agent proposes; deterministic code
   re-fetches live state and applies only if guards still hold) → PR-promotion
   contract (changed-file allowlist, base SHA, validation gate, draft-by-default)
   → cockpit lanes (`crabfleet`). **Caveat:** no OpenClaw repo solves merge-landing
   — CE still designs its own merger-agent/queue (#131).
2. **WS-5 — evidence ledger before the first release, not after** (`releases`):
   two-stage preflight→publish, blocking-vs-advisory check classification,
   provenance + artifact metadata; missing evidence = release blocker. Couples
   #80 + #133.
3. **WS-1/WS-3 — runtime access as capability *leases*:** disposable seats get
   explicit lease state/TTL/idle-cleanup + warm pools (`crabbox`); one root-bound
   FS primitive vs scattered path checks (`fs-safe`); two-phase install (hardened
   host envelope → product onboarding) with `doctor`/`sync-plan` canaries.
4. **WS-4 — token relay / read broker** (`octopool`): keep GitHub credentials out
   of agents; route policy + cache partitioning + identity rechecks. Aligns #113.
5. **WS-7 → feeds CRIT — `clawbench` validates "grader outside the agent":** score
   harness+config+model+runtime; deterministic verifier first + optional LLM judge
   second; full transcript/artifact capture; pass^k reliability.

**Validates our direction:** governed automation beats autonomous mutation
(proposal/apply split everywhere); containment + disposable seats are the right
substrate; release integrity needs first-class evidence.

**Cautions:** don't copy OpenClaw's weaker trust posture (trusted-team /
public-repo — CE needs hostile containment, private-repo tenancy, secret
custody); keep Python (the transferable assets are state-machines, ledgers,
schemas, gates — not code); don't let WS-7 sprawl.
