## Principal Gaps

- Formal SLSA Build provenance and Source VSA/source-provenance attestations are
  not yet emitted and distributed for every artifact/revision.
- SLSA Build L3 is not claimable until CE has a repo-visible hardened builder
  assessment and non-falsifiable provenance chain.
- SSDF RV.3 needs vulnerability-specific root-cause records and recurrence
  controls, not only general incident/rollback policy.
- Live GitHub settings are intentionally not mutated by repo changes; branch
  protection/CODEOWNERS rows therefore cite repo-visible policy and should be
  paired with live-settings evidence during an external audit.
